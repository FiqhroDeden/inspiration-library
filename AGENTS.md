# inspiration-library

Static app, no build, no dependencies. `index.html` is the whole UI, `library.js` is the data.

When asked to add a design screenshot / reference / URL to the library, follow
`.claude/skills/add-to-library/SKILL.md` exactly. It defines the entry schema and the rules
for keywords, image prompts, and briefs.

Validate any edit to `library.js` with `node check.mjs`.
